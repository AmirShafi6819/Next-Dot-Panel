# Code of Conduct

Next.Panel follows the [Contributor Covenant](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).
Be kind, be professional, assume good intent, and keep discussion technical.

Unacceptable behavior includes harassment, personal attacks, publishing
private information without consent, and any conduct that would reasonably
make contributors feel unsafe.

Violations can be reported privately to the repository owner. Until a
dedicated contact is published, use a private GitHub Security Advisory or a
direct message to a maintainer — do not litigate conduct issues in public
threads.
